About this site

Small on purpose.

Our Fine Family is a static home for selected personal and professional work. It has no tracking scripts, advertising, accounts, or application server—and no ambition to acquire them without a good reason.

How it is built

The site is ordinary HTML and CSS hosted on Cloudflare Pages. A Git commit is the publishing workflow. Keeping the machinery small makes the content easy to own, move, understand, and maintain.

Boundaries

Public projects and analysis live here. Private family information, personal daily briefings, and nonpublic professional material do not. Views expressed on this site are personal.

No trackers. No accounts. No fuss.
